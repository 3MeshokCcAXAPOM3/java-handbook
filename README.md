# VibeOFF

**Выруби автопилот. Вруби мозги.**

Автор: **Антон Сынушкин** · версия **v1.1** · обратная связь: MeshokCcAXAPOM@yandex.ru

VibeOFF — офлайн-тренажёр и учебник Java-разработчика: от основ языка до архитектуры, инфраструктуры и проектирования систем. Он создан, чтобы не забывать навыки программирования, пока быстро развиваются технологии искусственного интеллекта: ассистенты пишут всё больше кода, а понимать, проверять и принимать решения по-прежнему должен разработчик.

Работает без интернета и без установки: всё нужное (шрифты, подсветка кода, изображения, база SQLite) лежит в этой папке.

## Как открыть

1. Откройте файл **`VibeOFF.html`** (в скачанном архиве — **`index.html`**) двойным щелчком.
2. Он откроется в браузере по умолчанию. Рекомендуются Microsoft Edge, Google Chrome или Firefox последних версий.

Папку можно копировать на флешку или другой компьютер целиком — приложение продолжит работать.

## Онлайн-версия и обновления

Сайт: https://3meshokccaxapom3.github.io/VibeOFF/ — там же кнопка «⬇ Скачать» (архив для работы без интернета: распакуйте и откройте `index.html`). Когда выходит новая версия, приложение показывает плашку: на сайте — «Обновить», в скачанной копии — «Скачать». Обратная связь со страницы «О приложении» отправляется через сервис FormSubmit; без интернета откроется почтовая программа.

## Оформление

Кнопка **◐** справа вверху: тема (светлая, тёмная, как в системе) и стиль — Soft Lime (по умолчанию), Sage, Terminal Green, Electric Lime или Классика. Схемы перерисовываются под тёмную тему.

## Профили и сохранение прогресса

- Прогресс, заметки, результаты тестов, черновики кода и настройки сохраняются **автоматически** — ничего экспортировать не нужно.
- Если приложением пользуются несколько человек на одном компьютере, создайте каждому **свой профиль**: меню с именем под логотипом → «Новый профиль».
- Данные хранятся в браузере на этом компьютере: в другом браузере прогресс будет свой; очистка данных сайтов удалит и прогресс; при копировании папки на другой компьютер прогресс не переносится.

| `Esc`, `←`, `→` | закрыть окно; в просмотре изображений — листать |

## Телефоны

Скопируйте папку целиком и откройте `VibeOFF.html` в браузере телефона: внизу — панель быстрого перехода, меню открывается кнопкой ☰ или «Темы», страницы перестраиваются в одну колонку.
