# Java-справочник

Автор: **Антон Сынушкин** · версия **v0.9**

Офлайн-учебник и справочник Java-разработчика: от основ языка до архитектуры, инфраструктуры и проектирования систем. Подходит и тем, кто только начинает (Junior), и опытным инженерам (Senior, Staff).

Работает без интернета и без установки: всё нужное (шрифты, подсветка кода, изображения) лежит в этой папке.

## Как открыть

1. Откройте файл **`Java-справочник.html`** двойным щелчком.
2. Он откроется в браузере по умолчанию. Рекомендуются Microsoft Edge, Google Chrome или Firefox последних версий.

Папку можно копировать на флешку или другой компьютер целиком — справочник продолжит работать.

## Профили и сохранение прогресса

- Прогресс (отметки «Знаю / Повторить»), заметки, результаты тестов и экзаменов, черновики кода и настройки сохраняются **автоматически** — ничего экспортировать не нужно.
- Если справочником пользуются несколько человек на одном компьютере, создайте каждому **свой профиль**: меню с именем под логотипом слева → «Новый профиль». Данные профилей не смешиваются.
- Данные хранятся в браузере на этом компьютере. Поэтому:
  - в другом браузере (например, Firefox вместо Edge) прогресс будет свой, отдельный;
  - очистка данных сайтов в настройках браузера удалит и прогресс;
  - при копировании папки на другой компьютер прогресс не переносится.

## Клавиши

| Клавиша | Действие |
|---|---|
| `/` или `Ctrl+K` | поиск |
| `R` | случайный вопрос |
| `1`–`5` | уровень ответа: Junior, Middle, Senior, Все, Подробно |
| `Пробел` | в тренировке — показать ответ |
| `1`–`9`, `Enter` | в самотесте и экзамене — выбрать вариант, проверить, дальше |
| `Tab`, `Shift+Tab`, `Ctrl+/` | в редакторе кода — отступ, убрать отступ, закомментировать строки |
| `Esc`, `←`, `→` | в просмотре изображений — закрыть, листать |

Справа вверху — переключатель светлой и тёмной темы.
